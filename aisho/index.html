相性占い

恋愛、結婚、価値観、仕事、距離感。占術によって見ている角度は違います。ふたりの関係を、ひとつの物差しで決めつけずに見てみましょう。

占術を選ぶ

  • ✍️ 姓名判断の相性
    ふたりの名前の画数から、人格（性格）と総格（人生の方向性）の五行の関係を見る。生年月日がわからない相手とも    →
  • 🔢 数秘術の相性
    ライフパスなど複数の数字から、恋愛・結婚・価値観・仕事・親密さを見る    →
  • 🌗 星獣カルテの相性
    ふたりの星獣を、季節・月のリズム・星獣どうしの特徴から読む（オリジナル占い）    →
  • 🧭 九星気学の相性
    ふたりの本命星・月命星の五行の関係（比和・相生・相剋）から、価値観・会話・生活ペース・親密さを見る    →
  • ☯️ 四柱推命の相性
    日干どうしの干合・五行、お互いの通変星、日支（暮らし）の相性を見る    →
  • 🗿 マヤ暦の相性
    神秘KIN・ガイドKINなど運命の五角形の関係と、ふたりのKINを見る    →
  • 🌙 宿曜占星術の相性
    三九の秘法で、栄親・友衰・安壊・危成などの関係と距離を見る    →
  • 🌌 ホロスコープの相性
    太陽・月の星座の相性と、金星と火星など天体どうしの角度（シナストリー）を見る    →
  • 👑 紫微斗数の相性
    ふたりの命盤を重ね、命宮・夫妻宮・四化の飛び先・五行局から縁を見る（生まれた時刻が必要）    →
  • 🪷 インド占星術の相性
    インドで結婚相性に使われるアシュタクータ（グナ・ミラン）を36点満点で見る    →

  • 💭 恋人の夢・好きな人の夢
